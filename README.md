# Public Projects

A collection of software engineering and game development projects showcasing my work with C#, C++, Python, Unity, real-time systems, AI inference, and gameplay programming.

## Featured Projects

### TACO — Real-Time Pose Estimation

Real-time pose estimation and avatar animation system developed for Snapdragon X Elite hardware.

The application supports two pose-processing architectures:

* A native C++ integration using ONNX Runtime and the Qualcomm QNN backend for direct NPU inference
* A Python WebSocket backend used for development, testing, and comparison

The Unity frontend captures webcam input, processes pose information, and maps detected human movement onto an animated character.

**Technologies:** Unity, C#, C++, Python, ONNX Runtime, WebSockets, Qualcomm QNN, Snapdragon X Elite

### Bad Omen — Turn-Based Roguelike

A Unity turn-based roguelike featuring randomized combat encounters, elemental affinities, persistent player progression, item management, moveset upgrades, animated reward wheels, and boss-specific progression systems.

The project includes interconnected gameplay systems for turn management, enemy targeting, damage calculation, UI, resource management, and randomized rewards.
